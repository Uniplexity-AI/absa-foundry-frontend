The app is bootstrapped by `src/main.js` into a Vue 3 + Pinia SPA whose routes are declared in `src/router/index.js` and mounted inside layout components under `src/components/layouts/`. Cross-cutting concerns are split into dedicated layers: `src/stores/` holds global state (auth, dashboard, ETL, models, predictions), `src/composables/` provides reusable logic (bulk selection, RBAC, settings per domain, telemetry), `src/services/` centralizes all HTTP calls via axios wrappers (`api.js`, `auth_api.js`, `crm_*_api.js`, etc.), and `src/config/` supplies shared RBAC rules, module cards, currency and preferences. Views live under `src/views/Modules/<feature>/` for each business area (CRM, AI Agents, Data Pipeline, Intelligence, Strategic, Settings) plus auth and public pages. A Node/Express `server.js` serves the Vite `dist/` bundle with no-cache HTML and aggressive asset caching, while `vite.config.js` configures the PWA via `vite-plugin-pwa` using an injected `src/sw.js` service worker and `public/manifest.json`. The build pipeline runs `scripts/update-sw-cache.js` before `vite build` to keep the SW cache in sync, and tests are run through Vitest against component and composable specs.
