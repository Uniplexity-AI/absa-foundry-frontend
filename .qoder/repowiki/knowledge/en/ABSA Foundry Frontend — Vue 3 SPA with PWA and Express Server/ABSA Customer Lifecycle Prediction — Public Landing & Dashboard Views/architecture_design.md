Each file is a Vue 3 `<script setup>` single-file component mounted under `src/views/` and registered via the app router. The module splits into three functional groups: (1) public-facing entry points (`Home.vue`, `InitialisationScreen.vue`) that present marketing content and a timed splash screen before redirecting to `/login`; (2) authenticated dashboard screens (`DashboardHome.vue`, `PortfolioOverview.vue`, `CustomerDetail.vue`, `TakeAction.vue`, `CreateActionPlan.vue`) that consume shared Pinia stores (`useCustomerStore`, `usePredictionStore`) and composable utilities (`useRBAC`, `useCurrency`, `useDashboardWidgets`) to display KPI cards, a predictive lifecycle ledger table, alerts, health charts, and per-customer action forms; (3) utility/error routes (`403.vue`, `PWATestPage.vue`). Cross-cutting concerns are delegated outward: JWT decoding via `@/services/decodeJWT.js`, API calls through `@/services/api`, RBAC via `@/composables/useRBAC`, and reusable UI primitives from `@/components/ui/*` and `@/components/absa/*`. Each view owns its scoped CSS using an `absa-*` BEM naming scheme and Tailwind utility classes, with no cross-view imports between sibling files — communication happens exclusively through stores, route params/query, and shared composables.
